# Ramais

> Diretório corporativo de ramais — consulta rápida, simples e sempre atualizado.

## Sobre

O **Ramais** é um site leve para centralizar os contatos internos de uma organização. Lista ramal, nome, cargo, setor e e-mail com busca instantânea e agrupamento por setor — sem necessidade de banco de dados.

A consulta é aberta a todos; o gerenciamento é restrito a usuários autenticados.

## Para que serve

- **Encontrar contatos em segundos** — Busca inteligente por ramal, nome, setor, cargo ou e-mail.
- **Manter o diretório organizado** — Cadastro, edição e exclusão; o mesmo ramal pode ser de várias pessoas.
- **Exportar e imprimir** — Geração de planilha XLSX e versão para impressão/PDF.
- **Gerenciar acesso** — Perfis Admin e Editor com controle de permissões e troca de senha.

## Destaques

- Busca ao vivo com destaque do termo e tolerância a acentos
- Agrupamento por setor com expandir/minimizar
- Exportação formatada e impressão otimizada
- Armazenamento em arquivos JSON — backup simples
- Interface responsiva e leve em PHP puro

## Tecnologias

PHP · JSON · HTML/CSS/JS puro
